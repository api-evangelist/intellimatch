# IntelliMatch (FIS Data Integrity Manager)

> IntelliMatch is a transaction and account reconciliation platform originally built by SunGard
> and now sold by FIS, and since renamed **FIS Data Integrity Manager**. It performs account-level
> balance and transaction proofing at high volume and runs review, approval, exception management
> and escalation through an integrated workflow engine, for financial institutions and corporates
> reconciling cash, securities and intercompany activity. It is SWIFT-accredited and is sold both
> customer-hosted and as the FIS Optimized Reconciliation Service (formerly Managed Reconciliation
> Service, MRS).

## Machine-readable surface

**There is none.** As of 2026-09-13 FIS publishes no OpenAPI, AsyncAPI, GraphQL SDL, WSDL,
Protobuf, Postman collection, MCP server, A2A agent card or developer portal for this product.
The live product page carries no developer or integration reference and no link to one. Probes
against every host this record knows found one machine-readable document only: an RFC 9116
security.txt on the fisglobal.com apex, which is FIS corporate-wide rather than product-specific.

Integration with this product is arranged commercially with FIS. FIS's public API marketplace,
Code Connect (https://codeconnect.fisglobal.com/), carries FIS's core banking, payments, wealth
and accounting-data APIs — it is profiled separately at api-evangelist/fis — and its catalog
backend returns HTTP 403 to anonymous callers, so whether a Data Integrity Manager API is listed
inside it could not be established without credentials.

If you are an agent looking for a callable FIS surface, go to the FIS profile, not this one.
